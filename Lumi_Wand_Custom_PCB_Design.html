Lumi Wand — Custom PCB Design (DEPRECATED)

Company: DrDev Product: LumiAI Robotic Arm — Lumi Arc Document: Custom KiCad PCB Designs — Historical Reference Status: DEPRECATED 2026-05-02 — superseded by off-the-shelf PT4115 module design Date: March 2026 (initial); archived 2026-05-02

THIS DOCUMENT IS HISTORICAL. It describes two custom KiCad PCB designs (prototype MOSFET + production PT4115) that were designed, fabricated, and partially assembled during March-April 2026 before being abandoned in favor of off-the-shelf PT4115 modules. The PCBs and parts are kept in inventory but not maintained.

Active design: Lumi_Wand_LED_Fixture_Design.md — uses 12× off-the-shelf PT4115 modules + PCA9685 breakout in a clamshell PETG handle.

Why deprecated:

  • JLCPCB fab + Freerouter routing + SMT assembly workflow eliminated
  • 12× drop-in modules with screw terminals replace ~80 SMT joints (PCA9685 TSSOP-28, PT4115 SOT-89-5, 0805 sense resistors, etc.)
  • 4-wire arm tether recovered (was 13-14 conductors when the production PCB was relocated to the robot base for thermal/EMI reasons)
  • ~$10/unit cheaper, zero fab overhead, instant turnaround once parts in hand

3. Prototype Circuit (per channel)

PCA9685 PWM Out ─── 100Ω ──── IRLZ44N Gate
                               │
                         100kΩ ┤ (pull-down)
                               │
                              GND

10V+ ──── LED+ (anode)
           LED (chip)
           LED- (cathode) ──── MOSFET Drain
                               MOSFET Source ──── GND

(Inline 10Ω 5W on cathode wire between PCB JST output and LED star,
 housed in robot base alongside the PCB)
  • Current: I = (10V − Vf) / 10Ω ≈ 700 mA
  • MOSFETs run cold (Rds_on = 0.022Ω)
  • Resistors run very hot (~5W each, 60W total for 12 channels)

Routing workflow (Freerouter)

Production PCB was generated programmatically via gen_prod_pcb.py (placement only) and routed externally:

  1. KiCad 8 → File → Export → Specctra DSN
  2. Open DSN in Freerouter v2.1
  3. Click "Autoroute" → wait for completion
  4. File → Export → Specctra Session (.ses)
  5. Back in KiCad: File → Import → Specctra Session
  6. Press B (Fill All Zones) to connect GND zone
  7. Run DRC → 0 violations, 0 unconnected

DRC status (final)

  • Prototype: 6 unconnected items (1 real Q8 stub, 5 cosmetic GND zone islands), 48 lib_footprint env warnings, 42 silkscreen rule warnings (cosmetic)
  • Production: 0 unconnected, 59 lib_footprint env warnings, cosmetic silk warnings only

9. PCB Location — Robot Base Mounting

The PCBs were originally designed to fit inside the wand handle (30×25×55 mm) but were too large; both ended up mounted in the robot base on top of the LiFePO4 battery's retainer plate. This added EMI complications because the 12× PT4115 SW nodes (500 kHz switching) ran ~100 cm through the arm cable, parallel to the servo bus.

EMI mitigation options considered (none applied — design abandoned before bring-up):

  1. Accept and shield (braid + ferrites + twisted pairs)
  2. Move inductors + diodes + sense resistors to a small daughter board at the wand head
  3. Put PT4115 array back at the wand head (essentially the off-the-shelf module path that ultimately won)
