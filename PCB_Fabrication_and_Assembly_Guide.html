4. Production PCB — Routing with Freerouter

The production PCB is generated programmatically (no schematic). Traces must be routed externally.

Routing Workflow

  1. Open Lumi_Wand_12CH_Driver_PROD.kicad_pcb in KiCad 8
  2. File → Export → Specctra DSN
  3. Open DSN file in Freerouter v2.1 (on Win11)
  4. Click "Autoroute" → wait for completion
  5. File → Export → Specctra Session (.ses)
  6. Back in KiCad: File → Import → Specctra Session
  7. Press B (Fill All Zones) to connect GND zone
  8. Run DRC → should be 0 violations, 0 unconnected
  9. File → Fabrication Outputs → Gerbers → Plot
  10. File → Fabrication Outputs → Drill Files → Generate
  11. ZIP the gerbers folder → upload to JLCPCB

DRC Status

Production PCB is DRC clean — 0 violations, 0 unconnected pads after Freerouter + zone fill.

5. Prototype Circuit (per channel)

PCA9685 PWM Out ─── 100Ω ──── IRLZ44N Gate
                               │
                         100kΩ ┤ (pull-down)
                               │
                              GND

10V+ ──── LED+ (anode)
           LED (chip)
           LED- (cathode) ──── MOSFET Drain
                               MOSFET Source ──── 10Ω 5W ──── GND
  • Current: I = V / R = ~7V / 10Ω = ~700mA
  • MOSFETs run cold (Rds_on = 0.022Ω)
  • Resistors run very hot (~4.3W each, 52W total for 12 channels)

6. Production Circuit (per channel)

         VIN (Pin 2)
          |
10V+ ────+         +── Inductor (47uH) ── LED+ (anode)
          |         |
          PT4115 SW─+
          |    |
          |   SS14 diode
          |    | (freewheeling: cathode=SW, anode=GND)
          |   GND
          |
     DIM (Pin 4) <── PCA9685 CH output (PWM, 3.3V logic)
          |
     CSN (Pin 5) ── 0.15Ω sense ── GND
                         |
                    LED- (cathode)
          |
     GND (Pin 1) ── GND
  • Current: I = 0.1V / 0.15Ω = 667mA ≈ 700mA
  • Dimming: PCA9685 sends 1kHz PWM to PT4115 DIM pin
  • No MOSFET needed — PT4115 handles switching internally
  • ~95% efficient, ~4.2W total heat waste

8. Assembly — Soldering Order

Production PCB (recommended order)

Step Components Notes
1 U1 (PCA9685 TSSOP-28) Finest pitch — do first with clean board. Use flux + drag solder
2 All 0805 passives (C1-C14, R1-R12, R_SDA, R_SCL) Small SMD. Tweezers + fine tip iron
3 U2-U13 (PT4115 SOT-89-5) 12x ICs. Use flux, align carefully
4 D1-D12 (SS14 SMA) 12x diodes. Cathode band orientation critical
5 L1-L12 (47uH CD43 inductors) 12x inductors. Larger pads, solder last of SMD
6 J1 (JST-XH 5-pin) Through-hole, solder from bottom
7 J2, J3, J4 (1x9 pin headers) Through-hole
8 MH1, MH2 (M2 mounting holes) Optional — just pass-through pads

Prototype PCB (recommended order)

Step Components Notes
1 U1 (PCA9685 TSSOP-28) Same as production
2 All 0805 passives (100Ω, 100kΩ, caps) SMD
3 IRLZ44N MOSFETs (12x TO-220) Through-hole, bend leads
4 10Ω 5W resistors (12x) Through-hole, leave clearance for heat
5 Connectors (JST-XH, pin headers) Through-hole

9. Testing After Assembly

Step 1: Visual Inspection

  • Check for solder bridges (especially PCA9685 TSSOP-28 pins)
  • Verify diode orientation (cathode band)
  • Verify PT4115 pin 1 (GND) orientation
  • Check all solder joints under magnification

Step 2: Power Test (no LEDs)

# Connect 10V+ and GND only (no LEDs yet)
# Measure current draw — should be < 50mA (PCA9685 idle)
# If high current → short circuit, inspect immediately

Step 3: I2C Communication

# Connect SDA, SCL, 3V3 to Raspberry Pi 5
i2cdetect -y 1
# Should show PCA9685 at address 0x40

Step 4: Channel Test (with LEDs)

# Python test — light each channel at 50% PWM
from adafruit_pca9685 import PCA9685
import board, busio

i2c = busio.I2C(board.SCL, board.SDA)
pca = PCA9685(i2c)
pca.frequency = 1000  # 1kHz for PT4115 DIM pin

# Test channel 0 (LED1 Red)
pca.channels[0].duty_cycle = 0x7FFF  # 50% PWM

# Test all 12 channels sequentially
import time
for ch in range(12):
    pca.channels[ch].duty_cycle = 0x7FFF
    time.sleep(0.5)
    pca.channels[ch].duty_cycle = 0

Step 5: Current Verification (production only)

  • Measure voltage across any 0.15Ω sense resistor
  • Should read ~0.1V (= 667mA through LED)
  • If voltage is 0V → PT4115 not switching, check DIM pin

12. Troubleshooting

Symptom Likely Cause Fix
PCA9685 not detected on I2C SDA/SCL swapped, pull-ups missing, 3V3 not connected Check wiring, verify 10kΩ pull-ups soldered
LED doesn't light Wrong channel, diode reversed, PT4115 not getting VIN Check PWM output with scope, verify VIN at pin 2
LED flickers Poor solder joint on sense resistor, loose inductor Reflow solder joints on that channel
All LEDs dim VIN too low, sense resistor wrong value Measure VIN (should be 10V), verify 0.15Ω marking (0R15)
PT4115 gets very hot Shorted inductor, wrong diode orientation Check SS14 cathode → SW, anode → GND
Prototype resistors smoking Normal at full power (52W total) Run at ≤50% PWM, or switch to production PT4115 board
