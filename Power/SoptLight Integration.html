Overview

All LumiAI robotic arms include a gripper-mounted RGBW Intelligent Vision System as standard equipment. This document covers the complete integration of the 5050 RGBW 10W LED spotlight system with RPi5 PWM control.

Hardware Architecture

RGBW Spotlight System (Standard on ALL Models)

Key Decision: RGBW LED is CHEAPER than white LED + relay, so it's standard on all tiers!

Cost Comparison:

  • Old approach (White LED + Relay): $13.00
  • New approach (RGBW + MOSFETs): $5.15
  • Savings: $7.85 per unit!

All Tiers Use Identical RGBW System

No tier differentiation in lighting - all get the same premium system:

  • Entry Tier ($599): 5050 RGBW 10W LED (standard)
  • Mid Tier ($799): 5050 RGBW 10W LED (standard)
  • Premium Tier ($999): 5050 RGBW 10W LED (standard)

Differentiation is in camera capability, not lighting!

Wiring Diagram (RGBW with RPi5 PWM)

Raspberry Pi 5 GPIO (5V)
    ├─ GPIO 12 (PWM0) → MOSFET 1 Gate (Red)
    ├─ GPIO 13 (PWM1) → MOSFET 2 Gate (Green)
    ├─ GPIO 18 (PWM0) → MOSFET 3 Gate (Blue)
    ├─ GPIO 19 (PWM1) → MOSFET 4 Gate (White)
    └─ GND → 10kΩ pull-down resistors

Each MOSFET (IRLZ44N):
    ├─ Gate → GPIO + 10kΩ to GND
    ├─ Source → GND
    └─ Drain → LED channel (+)

5050 RGBW LED (on heatsink):
    ├─ R+ → MOSFET 1 Drain
    ├─ G+ → MOSFET 2 Drain
    ├─ B+ → MOSFET 3 Drain
    ├─ W+ → MOSFET 4 Drain
    └─ R-, G-, B-, W- → GND

Power Supply:
    └─ 5V from RPi5 PSU → LED common (+) via MOSFETs

Software Integration

RGBW PWM Control (Using pigpio) 🎯

Why pigpio:

  • ✅ Hardware PWM support (smooth, flicker-free)
  • ✅ 4 independent channels for RGBW
  • ✅ 0-100% dimming per channel
  • ✅ No external controller needed (RPi5 built-in)

Create ROS2 RGBW Controller

Create the node at /home/ubuntu/ros2_ws/src/spotlight_controller/spotlight_controller/rgbw_spotlight_node.py (or scripts/rgbw_spotlight_node.py if using scripts; see Package Structure below):

#!/usr/bin/env python3
"""
ROS2 RGBW Spotlight Controller Node
Controls 5050 RGBW 10W LED via RPi5 hardware PWM (pigpio)
"""

import rclpy
from rclpy.node import Node
from std_msgs.msg import ColorRGBA
from std_srvs.srv import Trigger, SetBool
from interfaces.srv import SetInt64
import pigpio

class RGBWSpotlightNode(Node):
    def __init__(self):
        super().__init__('rgbw_spotlight_controller')
        
        # Initialize pigpio for hardware PWM
        self.pi = pigpio.pi()
        if not self.pi.connected:
            self.get_logger().error('❌ Failed to connect to pigpiod')
            raise RuntimeError('pigpiod not running - run: sudo systemctl start pigpiod')
        
        # RGBW GPIO pins (hardware PWM)
        self.pin_r = 12  # Red channel (PWM0)
        self.pin_g = 13  # Green channel (PWM1)
        self.pin_b = 18  # Blue channel (PWM0)
        self.pin_w = 19  # White channel (PWM1)
        
        # PWM Configuration
        self.pwm_freq = 1000  # 1kHz (flicker-free)
        self.pwm_range = 255  # 0-255 duty cycle
        
        # Setup PWM on all channels
        for pin in [self.pin_r, self.pin_g, self.pin_b, self.pin_w]:
            self.pi.set_mode(pin, pigpio.OUTPUT)
            self.pi.set_PWM_frequency(pin, self.pwm_freq)
            self.pi.set_PWM_range(pin, self.pwm_range)
        
        # State
        self.current_color = (255, 255, 255, 255)  # RGBW (all white)
        self.brightness = 100  # 0-100%
        self.is_on = False
        
        # Subscribers
        self.create_subscription(
            ColorRGBA,
            '/spotlight/set_color',
            self.color_callback,
            10
        )
        
        # Services
        self.create_service(SetBool, '/spotlight/set_state', self.set_state_callback)
        self.create_service(SetInt64, '/spotlight/set_brightness', self.set_brightness_callback)
        self.create_service(Trigger, '/spotlight/toggle', self.toggle_callback)
        # Optional: self.create_service(Trigger, '/spotlight/pulse', self.pulse_callback)  # 1s flash for menu option 4
        
        self.get_logger().info('🌈 RGBW Spotlight controller initialized')
    
    def color_callback(self, msg):
        """Set spotlight color from ColorRGBA message"""
        r = int(msg.r * 255)
        g = int(msg.g * 255)
        b = int(msg.b * 255)
        w = int(msg.a * 255)  # Use alpha channel for white
        self.current_color = (r, g, b, w)
        
        if self.is_on:
            self.update_led()
        
        self.get_logger().info(f'🎨 Color set to RGBW({r}, {g}, {b}, {w})')
    
    def set_state_callback(self, request, response):
        """Turn spotlight on/off"""
        self.is_on = request.data
        self.update_led()
        
        response.success = True
        response.message = f"RGBW Spotlight {'ON' if self.is_on else 'OFF'}"
        self.get_logger().info(f'💡 {response.message}')
        return response
    
    def set_brightness_callback(self, request, response):
        """Set brightness (0-100%)"""
        self.brightness = max(0, min(100, request.data))
        
        if self.is_on:
            self.update_led()
        
        response.success = True
        response.message = f"Brightness: {self.brightness}%"
        self.get_logger().info(f'💡 {response.message}')
        return response
    
    def toggle_callback(self, request, response):
        """Toggle spotlight state"""
        self.is_on = not self.is_on
        self.update_led()
        
        response.success = True
        response.message = f"RGBW Spotlight {'ON' if self.is_on else 'OFF'}"
        self.get_logger().info(f'💡 {response.message}')
        return response
    
    def update_led(self):
        """Update LED RGBW values with brightness"""
        if self.is_on:
            r, g, b, w = self.current_color
            # Apply brightness scaling
            brightness_factor = self.brightness / 100.0
            r_pwm = int(r * brightness_factor)
            g_pwm = int(g * brightness_factor)
            b_pwm = int(b * brightness_factor)
            w_pwm = int(w * brightness_factor)
            
            self.pi.set_PWM_dutycycle(self.pin_r, r_pwm)
            self.pi.set_PWM_dutycycle(self.pin_g, g_pwm)
            self.pi.set_PWM_dutycycle(self.pin_b, b_pwm)
            self.pi.set_PWM_dutycycle(self.pin_w, w_pwm)
        else:
            # Turn off all channels
            self.pi.set_PWM_dutycycle(self.pin_r, 0)
            self.pi.set_PWM_dutycycle(self.pin_g, 0)
            self.pi.set_PWM_dutycycle(self.pin_b, 0)
            self.pi.set_PWM_dutycycle(self.pin_w, 0)
    
    def cleanup(self):
        """Turn off LED and cleanup"""
        self.pi.set_PWM_dutycycle(self.pin_r, 0)
        self.pi.set_PWM_dutycycle(self.pin_g, 0)
        self.pi.set_PWM_dutycycle(self.pin_b, 0)
        self.pi.set_PWM_dutycycle(self.pin_w, 0)
        self.pi.stop()
        self.get_logger().info('🔦 RGBW Spotlight controller cleaned up')

def main():
    rclpy.init()
    node = RGBWSpotlightNode()
    
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.cleanup()
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

# Spotlight control functions
start_spotlight_controller() {
    if [ -f "$PIDS_DIR/spotlight.pid" ] && kill -0 "$(cat $PIDS_DIR/spotlight.pid)" 2>/dev/null; then
        echo -e "${YELLOW}💡 Spotlight Controller already running - skipping${NC}"
        return
    fi
    
    echo -e "${GREEN}💡 Starting Spotlight Controller...${NC}"
    setup_ros2_env
    nohup ros2 run spotlight_controller rgbw_spotlight_node \
        2>&1 | ts_log >> /tmp/armpi_fpv_spotlight.log &
    echo $! > "$PIDS_DIR/spotlight.pid"
    echo -e "${GREEN}✅ Started with PID: $!${NC}"
}

stop_spotlight_controller() {
    echo -e "${YELLOW}Stopping Spotlight Controller...${NC}"
    if [ -f "$PIDS_DIR/spotlight.pid" ]; then
        kill "$(cat $PIDS_DIR/spotlight.pid)" 2>/dev/null || true
        rm -f "$PIDS_DIR/spotlight.pid"
    fi
    pkill -9 -f "rgbw_spotlight_node" 2>/dev/null || true
    echo -e "${GREEN}✅ Stopped Spotlight Controller${NC}"
}

toggle_spotlight_controller() {
    if [ -f "$PIDS_DIR/spotlight.pid" ] && kill -0 "$(cat $PIDS_DIR/spotlight.pid)" 2>/dev/null; then
        stop_spotlight_controller
    else
        start_spotlight_controller
    fi
}

# Spotlight control menu
control_spotlight() {
    setup_ros2_env
    echo -e "${YELLOW}💡 Spotlight Control${NC}"
    echo ""
    echo "1. 🔴 Off"
    echo "2. 🟢 On"
    echo "3. 🔄 Toggle"
    echo "4. ⚡ Pulse (1s flash)"
    echo "5. 🌙 Low (25%)"
    echo "6. 🌗 Medium (50%)"
    echo "7. 🌕 High (100%)"
    echo "8. 🔙 Back"
    echo ""
    read -p "Select option: " choice
    
    case $choice in
        1) ros2 service call /spotlight/set_state std_srvs/srv/SetBool "{data: false}" ;;
        2) ros2 service call /spotlight/set_state std_srvs/srv/SetBool "{data: true}" ;;
        3) ros2 service call /spotlight/toggle std_srvs/srv/Trigger ;;
        4) ros2 service call /spotlight/pulse std_srvs/srv/Trigger ;;  # Implement pulse_callback in node for 1s flash
        5) ros2 service call /spotlight/set_brightness interfaces/srv/SetInt64 "{data: 25}" ;;
        6) ros2 service call /spotlight/set_brightness interfaces/srv/SetInt64 "{data: 50}" ;;
        7) ros2 service call /spotlight/set_brightness interfaces/srv/SetInt64 "{data: 100}" ;;
        8) return ;;
        *) echo -e "${RED}Invalid option${NC}" ;;
    esac
    
    sleep 1
}

Auto-Brightness with Ambient Light

Integration with Tracking Node

# In tracking_ros2_professional.py

class ObjectTrackingNode(Node):
    def __init__(self):
        # ... existing init ...
        
        # Spotlight control client
        self.spotlight_client = self.create_client(
            SetBool,
            '/spotlight/set_state'
        )
        
        # Ambient light threshold
        self.dark_threshold = 50  # lux
        
    def check_lighting(self):
        """Auto-enable spotlight in low light"""
        # If you have ambient light sensor
        if self.ambient_light < self.dark_threshold:
            self.enable_spotlight(True)
        else:
            self.enable_spotlight(False)
    
    def enable_spotlight(self, enable):
        """Enable/disable spotlight"""
        if self.spotlight_client.wait_for_service(timeout_sec=1.0):
            request = SetBool.Request()
            request.data = enable
            future = self.spotlight_client.call_async(request)

ros2 topic pub /spotlight/set_color std_msgs/msg/ColorRGBA "{r: 0.0, g: 1.0, b: 1.0, a: 0.0}"  # Cyan (G+B)

# Turn on/off
ros2 service call /spotlight/set_state std_srvs/srv/SetBool "{data: true}"
ros2 service call /spotlight/set_state std_srvs/srv/SetBool "{data: false}"

# Set brightness (0-100%)
ros2 service call /spotlight/set_brightness interfaces/srv/SetInt64 "{data: 50}"  # 50% brightness
ros2 service call /spotlight/set_brightness interfaces/srv/SetInt64 "{data: 100}"  # Full brightness

# Toggle on/off
ros2 service call /spotlight/toggle std_srvs/srv/Trigger
